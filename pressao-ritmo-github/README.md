# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/a07b78bb-d955-47ff-976b-be287ddb2b55

## Run Locally

**Prerequisites:**  [Android Studio](https://developer.android.com/studio)


1. Open Android Studio
2. Select **Open** and choose the directory containing this project
3. Allow Android Studio to fix any incompatibilities as it imports the project.
4. Run the app on an emulator or physical device

The app uses the standard Android debug keystore for local builds. Release builds are unsigned by default; configure a release keystore in Android Studio or your CI environment before publishing.
